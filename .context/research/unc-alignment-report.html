1. Resumen Ejecutivo

El Diploma Tracking System es el middleware de integración solicitado por la UNC para articular el recorrido de estudiantes en diplomaturas con módulos dictados en Moodle, validando equivalencias mediante un motor de reglas configurable, gestionando la inscripción a exámenes integradores, y automatizando la comunicación con SIU Guaraní para registro de notas y emisión de diplomas.

Estado actual: 45 endpoints API funcionales, 65 tests automatizados, frontend React desplegado, CI/CD operativo, documentación completa de backlog (25 historias con Gherkin AC y edge cases). Sistema auto-contenido en modo demo para presentación inmediata a stakeholders.
