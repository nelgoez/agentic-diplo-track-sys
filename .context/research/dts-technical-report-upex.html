1. Resumen Ejecutivo

Diploma Tracking System (DTS) — middleware de integración académica para UNC, supervisado por UPEX. Articula el recorrido de estudiantes en diplomaturas con cursos modulares, motor de reglas ALL/ANY, sincronización Moodle-Guaraní, y gestión de exámenes integradores.

Estado (30/05/2026): 43 endpoints · 65 tests (100%) · CI/CD green · Frontend + Server deployed · Mock Mode operativo · 59% MVP completo.

Patrones de Diseño

  • Provider Abstraction: CertificateProvider + AcademicProvider. Moodle API real, Guaraní mock realista. Activación por MOCK_MODE.
  • Middleware Chain: Logger → PrettyJSON → CORS → Authenticate → RequireRole → Zod Validator → Handler.
  • Dependency Injection: Motor de reglas recibe data access factory. Testeable sin DB real.
  • Idempotent Sync: UPSERT por clave natural. Conflict guard. Per-student + per-course error isolation.
  • Event-driven (light): Fire-and-forget diploma push post-grade. Non-blocking.

6.2 CI/CD Pipeline

on: [push, pull_request] → main, staging

Server — Typecheck + Tests
  └─ Typecheck → Unit tests (23, always pass) → API tests (42, needs secrets, non-blocking)

Client — Build
  └─ bun run build (Vite + React, always passes)
Secrets requeridos: SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, SUPABASE_ANON_KEY, JWT_SECRET, VITE_API_URL. Sin ellos, CI corre typecheck + unit tests. Con ellos, corre todo.
